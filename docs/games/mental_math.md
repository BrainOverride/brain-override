# ➕ 암산 스피드 (MentalMath)

> 30초 동안 사칙연산 문제를 최대한 많이 푸는 계산 속도 게임

| 항목 | 내용 |
| --- | --- |
| 클래스 | `MentalMath extends MiniGame` |
| 파일 | `src/games/MentalMath.java` |
| 담당 | 정종일 |
| 두뇌 영역 | 계산 · 처리 속도 |
| 구현 난도 | 하 |

---

## 1. 규칙

1. 시작하면 30초 타이머가 돌아갑니다.
2. 문제가 하나씩 나오고, 답을 입력하면 바로 다음 문제가 나옵니다.
3. 틀려도 패널티 없이 다음 문제로 넘어갑니다.
4. 30초 안에 **5문제 이상 맞히면 성공**입니다.

## 2. 화면 예시

```
=== 암산 스피드 (Hard) ===
30초 동안 5문제 이상 맞히세요! Enter를 누르면 시작합니다.

[남은 27초] 12 + 7 = 19     ✅
[남은 23초] 15 - 6 = 9      ✅
[남은 18초] 4 × 8 = 32      ✅
⚠ 지금부터 + 는 빼기, - 는 더하기입니다!
[남은 14초] 9 + 3 = 6       ✅
[남은 10초] 11 - 4 = 7      ❌ (정답: 15)
...
⏰ 시간 종료! 6문제 정답 → 성공
```

## 3. 난이도별 설정

| 난이도 | 연산 | 숫자 범위 | 특수 규칙 |
| --- | --- | --- | --- |
| Easy | `+`, `-` | 1~20 | 없음 |
| Normal | `+`, `-`, `×` | 덧셈·뺄셈 1~50, 곱셈 2~9 × 2~12 | 없음 |
| Hard | `+`, `-`, `×` | Normal과 같음 | **3문제마다 `+`와 `-`의 의미가 반전** |

- 뺄셈은 큰 수에서 작은 수를 빼도록 만들어 음수 답이 나오지 않게 합니다.
- 나눗셈은 넣지 않습니다. 나누어떨어지는 문제만 만들어야 해서 생성 로직이 복잡해지기 때문입니다.
- **시간 보너스**: 이 게임은 항상 30초를 다 쓰므로, 소요 시간 대신 **"5문제째 맞힌 시점"**을 `GameResult`에 넘깁니다. 빨리 목표를 달성할수록 보너스가 큽니다. 기준 시간은 30초입니다.

## 4. Hard: 연산자 반전 규칙

- 1~3번 문제는 정상, 4~6번은 반전, 7~9번은 정상… 처럼 **3문제마다 토글**합니다.
- 전환될 때마다 안내 문구를 표시합니다. 정상으로 돌아올 때도 안내합니다.
- `×`는 반전하지 않습니다. 모든 연산자가 바뀌면 "전부 반대로"라는 단순 암기가 되기 때문입니다.
- 반전 상태에서 빼기로 계산되는 `+` 문제도 음수가 나오지 않게 큰 수를 앞에 둡니다.

**왜 규칙 변화인가**: 계산 실력이 아니라 "기호를 보고 다른 연산을 떠올리는" 전환 능력을 요구합니다. 숫자 범위를 키우는 것과는 다른 종류의 어려움입니다.

### 구현 순서

1. 난이도별 사용할 연산자와 반전 여부를 조회합니다.
2. Enter 입력을 기다린 뒤 시작 시간을 기록합니다.
3. 남은 시간이 있는 동안 반복합니다.
   1. Hard면 지금이 반전 구간인지 계산하고, 바뀌는 순간이면 안내합니다.
   2. 문제를 만들고 정답을 계산합니다(반전 구간이면 `+`, `-`를 바꿔 계산).
   3. 남은 시간과 함께 문제를 출력하고 답을 입력받습니다.
   4. **입력 직후 시간을 다시 확인**합니다. 30초가 지났으면 이 답은 무효 처리하고 종료합니다.
   5. 맞으면 정답 수를 올리고, 5번째 정답이면 그 시점을 기록합니다.
4. 정답 수가 5 이상이면 성공입니다.

### `nextLine()` 대기 문제

`Scanner.nextLine()`은 답을 입력할 때까지 프로그램을 멈춥니다. 그래서 29초에 문제를 받고 1분 뒤에 답해도 중간에 끊을 수 없습니다. 이 게임은 **답을 받은 직후 시간을 확인해서, 30초가 지난 답은 무효 처리**하는 방식으로 해결합니다. 스레드를 쓰지 않아도 되므로 초보자도 구현할 수 있습니다.

### 쓸 만한 Java API

| 하고 싶은 것 | API |
| --- | --- |
| 경과 시간(초) | `(System.currentTimeMillis() - start) / 1000.0` |
| 범위 랜덤 | `random.nextInt(최대 - 최소 + 1) + 최소` |
| 연산자 고르기 | 연산자를 `char[]`나 `String`에 담고 랜덤 인덱스 |
| 정수 입력 | `ConsoleUtil.readInt(prompt)` |

## 6. 입력 검증

| 입력 | 처리 |
| --- | --- |
| 숫자가 아님 | 재입력 (문제는 그대로, 타이머는 계속 흐름) |
| 앞뒤 공백 | `trim()` 후 정상 처리 |

형식 오류도 시간은 흐릅니다. 시간 제한 게임이라 "기회"가 곧 시간이기 때문입니다.

## 7. 테스트 체크리스트

- [ ] Easy에 `×`가 나오지 않음
- [ ] 뺄셈 정답이 음수가 아님 (Hard 반전 상태 포함)
- [ ] 30초가 지난 뒤 입력한 답은 정답이어도 무효
- [ ] Hard: 4번째, 10번째 문제에서 반전 안내, 7번째 문제에서 정상 복귀 안내
- [ ] Hard: 반전 상태에서 `9 + 3`의 정답이 6으로 판정됨
- [ ] 5문제째 정답 시점이 `GameResult`의 소요 시간으로 기록됨
