# 🧭 미로 탈출 (MazeEscape)

> 미로를 보고 출구까지의 경로를 머릿속으로 그린 뒤, 한 번에 입력하는 공간 지각 게임

| 항목 | 내용 |
| --- | --- |
| 클래스 | `MazeEscape extends MiniGame` |
| 파일 | `src/games/MazeEscape.java`, `src/games/MazeData.java` |
| 담당 | 나혜빈 |
| 두뇌 영역 | 공간 지각 |
| 구현 난도 | 하~중 (미로 데이터 제작이 작업량의 대부분) |

---

## 1. 규칙

1. ASCII 미로가 표시됩니다. `S`는 출발점, `E`는 출구, `#`은 벽입니다.
2. 출구까지의 이동을 **방향 문자열로 한 번에** 입력합니다.
   - `U` 위, `D` 아래, `L` 왼쪽, `R` 오른쪽 (소문자도 허용)
3. 입력한 순서대로 한 칸씩 이동합니다.
   - 벽에 부딪히면 그 자리에서 실패하고, 부딪힌 위치를 보여줍니다.
   - 이동이 끝났을 때 `E`에 있으면 성공, 아니면 실패입니다.
4. **3번 안에 탈출하면 성공**입니다. 실패할 때마다 같은 미로로 다시 시도합니다.

## 2. 화면 예시

```
=== 미로 탈출 (Easy) ===  시도 1/3
# # # # # # #
# S . . # . #
# # # . # . #
# . . . . . #
# . # # # . #
# . . . # . E
# # # # # # #

경로 입력 (U/D/L/R): RRDDRRDD
  → 6번째 이동(R)에서 벽에 부딪혔습니다! 💥

# # # # # # #
# S * * # . #
# # # * # . #
# . . * * * #
# . # # # X #      ← 부딪힌 위치
...
```

- 길은 `.`, 지나온 칸은 `*`, 부딪힌 칸은 `X`로 표시해 어디서 틀렸는지 바로 보이게 합니다.
- 칸 사이에 공백을 넣어 출력합니다. 콘솔 글자는 세로로 길어서, 공백이 없으면 미로가 찌그러져 보입니다.

## 3. 난이도별 설정

| 난이도 | 크기(이동 가능 영역) | 시도 | 특수 규칙 | 시간 보너스 기준(제안) |
| --- | --- | --- | --- | --- |
| Easy | 5×5 | 3회 | 없음 | 60초 |
| Normal | 9×9 | 3회 | 없음 | 120초 |
| Hard | 9×9 | 3회 | **좌우 반전 조작** (`L` 입력 시 오른쪽 이동) | 150초 |

**3회 시도인 이유**: 경로를 한 번에 길게 입력하기 때문에, 공간 판단은 맞았는데 오타 하나로 실패할 수 있습니다. 기회 1회는 오타에 너무 가혹하고, 무제한이면 벽에 부딪혀 보며 길을 찾는 시행착오 게임이 됩니다.

## 4. Hard: 좌우 반전 규칙

- 시작할 때 `⚠ 좌우가 반전되었습니다! L = 오른쪽, R = 왼쪽`을 표시합니다.
- `U`, `D`는 그대로입니다. 네 방향을 다 바꾸면 "전부 반대로"라는 단순 규칙이 되지만, 좌우만 바꾸면 축마다 다르게 생각해야 해서 더 헷갈립니다.
- **구현 힌트**: 방향 문자 → (행 변화, 열 변화) 대응표를 하나 두고, Hard에서는 `L`과 `R`의 값만 바꾼 대응표를 씁니다. 이동 로직은 그대로입니다.

## 5. 미로 데이터 (`MazeData`)

미로는 **직접 그려서 난이도별로 3~4개** 준비하고, 매 게임 랜덤으로 하나를 고릅니다. 자동 생성 알고리즘은 3일 일정에 비해 이점이 없고, 손으로 그리면 헷갈리는 갈림길을 의도적으로 넣을 수 있습니다.

```java
public class MazeData {
    public static final String[][] EASY = {
        {
            "#######",
            "#S..#.#",
            "###.#.#",
            "#.....#",
            "#.###.#",
            "#...#.E",
            "#######",
        },
        // 2~3개 더
    };
    public static final String[][] NORMAL = { /* 9×9 미로 3~4개 */ };
}
```

**왜 별도 클래스인가**: 미로 데이터가 길어서 로직 파일에 넣으면 코드를 읽기 어렵습니다. 데이터만 고칠 때 로직을 건드리지 않아도 됩니다.

**미로 제작 규칙**
- 테두리는 모두 `#`, 출구 `E`는 테두리 위에 둡니다.
- 출발점에서 출구까지 **경로가 반드시 1개 이상** 있어야 합니다. 만들 때마다 직접 정답 경로를 적어두고 테스트합니다.
- 막다른 길을 2개 이상 넣어 한눈에 답이 보이지 않게 합니다.

## 6. 구현 가이드

### 클래스 뼈대

```java
public class MazeEscape extends MiniGame {

    public MazeEscape() { super("미로 탈출"); }

    @Override
    protected GameResult playRound(Difficulty difficulty) {
        // TODO
    }
}
```

### 구현 순서

1. 난이도별 미로 목록, 반전 여부를 조회하고 미로 하나를 랜덤으로 고릅니다.
2. 미로를 `char[][]`로 바꾸고 `S`의 위치를 찾습니다.
3. 시도 횟수만큼 반복합니다.
   1. 미로를 출력하고 경로를 입력받습니다(7절 검증).
   2. `S`에서 출발해 한 글자씩 이동합니다. 벽이면 몇 번째 이동인지 기록하고 멈춥니다.
   3. 끝까지 이동했고 현재 칸이 `E`면 성공 반환.
   4. 실패면 지나온 길과 충돌 위치를 표시해 보여줍니다.
4. 시도를 다 쓰면 실패 반환.

### 쓸 만한 Java API

| 하고 싶은 것 | API |
| --- | --- |
| 문자열 → 글자 배열 | `str.toCharArray()` |
| 대문자 변환 | `input.toUpperCase()` |
| 공백 제거 | `input.replace(" ", "")` |
| 허용 문자만 있는지 | `input.matches("[UDLR]+")` (정규식: U, D, L, R이 1개 이상) |
| 방향 대응표 | `Map<Character, int[]>` 예: `'U' → {-1, 0}` |

> 출력할 때 원본 미로를 직접 바꾸면 다음 시도에도 `*`가 남습니다. 표시용 복사본을 만들어 그 위에 `*`를 찍으세요.

## 7. 입력 검증 (시도 차감 없음)

| 입력 | 처리 |
| --- | --- |
| U/D/L/R 외 문자 포함 | 재입력 ("U, D, L, R만 입력하세요") |
| 빈 입력 | 재입력 |
| 소문자 | 대문자로 변환 후 정상 처리 |
| 공백 포함 (`RR DD`) | 공백 제거 후 정상 처리 |

## 8. 테스트 체크리스트

- [ ] 모든 미로에서 적어둔 정답 경로를 입력하면 성공
- [ ] 벽 충돌 시 몇 번째 이동인지 정확히 표시됨
- [ ] 이동이 끝났는데 `E`가 아니면 실패
- [ ] 실패 후 다음 시도에서 이전 `*` 표시가 남아 있지 않음
- [ ] 형식 오류 입력이 시도를 차감하지 않음
- [ ] Hard: `L` 입력 시 오른쪽으로 이동, `U`/`D`는 그대로
