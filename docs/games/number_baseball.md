# ⚾ 숫자야구 (NumberBaseball)

> 컴퓨터가 숨긴 숫자를 스트라이크 / 볼 힌트만으로 맞히는 추리 게임

| 항목 | 내용 |
| --- | --- |
| 클래스 | `NumberBaseball extends MiniGame` |
| 파일 | `src/games/NumberBaseball.java` |
| 담당 | 나혜빈 |
| 두뇌 영역 | 논리 추론 |
| 구현 난도 | 하~중 (Hard 거짓 힌트가 핵심) |

---

## 1. 규칙

1. 컴퓨터가 **0~9 중 중복 없는 N자리 숫자**를 정합니다. 맨 앞자리 0도 허용합니다.
2. 플레이어가 N자리 숫자를 입력하면 힌트를 받습니다.
   - **스트라이크(S)**: 숫자와 자리가 모두 맞음
   - **볼(B)**: 숫자는 있지만 자리가 다름
   - **아웃**: 맞는 숫자가 하나도 없음 (0S 0B)
3. 제한 횟수 안에 N스트라이크를 만들면 성공, 횟수를 다 쓰면 실패입니다.

## 2. 화면 예시

```
=== 숫자야구 (Normal) ===
0~9 중복 없는 4자리 숫자를 맞혀보세요. (기회 10회)

[1/10] 입력: 1234
  → 1S 1B
[2/10] 입력: 1567
  → 1S 0B
[3/10] 입력: 1122
  ⚠ 중복 없는 숫자 4자리를 입력하세요. (기회 차감 없음)
[3/10] 입력: 1083
  → 4S 🎉 정답! (3회 만에 성공)
```

## 3. 난이도별 설정

| 난이도 | 자릿수 | 기회 | 특수 규칙 | 시간 보너스 기준(제안) |
| --- | --- | --- | --- | --- |
| Easy | 3 | 10회 | 없음 | 180초 |
| Normal | 4 | 10회 | 없음 | 180초 |
| Hard | 4 | 8회 | **힌트 중 1회는 거짓** | 150초 |

> 시간 보너스 기준은 제안값입니다. Day 3 밸런스 조정 때 직접 플레이해 보고 확정합니다.

## 4. Hard: 거짓 힌트 규칙

- 시작할 때 **"힌트 중 1번은 거짓입니다"**라고 안내합니다. 몇 번째인지는 알려주지 않습니다.
- 거짓말할 회차는 게임 시작 시 미리 랜덤으로 정합니다. **마지막 회차는 제외**합니다. 마지막 기회가 거짓으로 날아가면 플레이어가 대응할 방법이 없기 때문입니다.
- 그 회차에 플레이어가 **정답을 맞혔다면 거짓말하지 않고 성공 처리**합니다.
- 게임이 끝나면 "3번째 힌트가 거짓이었습니다"처럼 공개합니다.

**거짓 힌트를 고르는 조건** (스스로 구현해 보세요)

거짓 힌트는 "실제로 나올 수 있는 조합 중 진짜와 다른 것"이어야 합니다. 말이 안 되는 힌트(예: 4자리에서 3S 1B)를 주면 플레이어가 거짓인 걸 바로 알아채기 때문입니다.

| 조건 | 이유 |
| --- | --- |
| S + B ≤ 자릿수 | 맞는 숫자 개수가 자릿수를 넘을 수 없음 |
| S = 자릿수(정답)는 제외 | 정답이라고 거짓말하면 게임이 끝나버림 |
| (자릿수 − 1)S 1B는 제외 | 숫자가 하나만 자리가 틀릴 수는 없음 (논리적으로 불가능) |
| 진짜 힌트와 같은 조합은 제외 | 거짓이 아니게 됨 |

## 5. 구현 가이드

### 클래스 뼈대

```java
public class NumberBaseball extends MiniGame {

    public NumberBaseball() { super("숫자야구"); }

    @Override
    protected GameResult playRound(Difficulty difficulty) {
        // TODO
    }
}
```

### 구현 순서

1. `difficulty.getLabel()`로 자릿수, 기회, 거짓말 여부를 `Map`에서 조회합니다.
2. 정답 만들기: 0~9를 리스트에 넣고 섞은 뒤 앞에서 N개를 씁니다.
3. 시작 시간을 기록합니다.
4. 기회만큼 반복합니다.
   1. 입력을 받고 검증합니다(6절). 형식이 틀리면 기회를 차감하지 않고 다시 받습니다.
   2. 스트라이크와 볼을 셉니다.
   3. N스트라이크면 성공 `GameResult`를 반환합니다.
   4. Hard이고 거짓말 회차면 힌트를 거짓으로 바꿉니다.
   5. 힌트를 출력합니다.
5. 반복이 끝나면 정답을 공개하고 실패 `GameResult`를 반환합니다.

### 스트라이크 / 볼 세는 방법 (힌트)

- **스트라이크**: 같은 위치의 글자가 같은 개수
- **볼**: 두 숫자에 공통으로 들어 있는 숫자 개수 − 스트라이크

예: 정답 `1234`, 입력 `1243` → 같은 자리 `1`, `2` → 2S. 공통 숫자 4개 − 2 = 2B.

### 쓸 만한 Java API

| 하고 싶은 것 | API |
| --- | --- |
| 리스트 섞기 | `Collections.shuffle(list)` |
| 문자열의 i번째 글자 | `str.charAt(i)` |
| 글자가 들어 있는지 | `str.indexOf(ch) >= 0` 또는 `str.contains(...)` |
| 랜덤 정수 | `new Random().nextInt(n)` → 0 ~ n-1 |
| 시간 측정 | `System.currentTimeMillis()` |

## 6. 입력 검증 (기회 차감 없음)

| 입력 | 처리 |
| --- | --- |
| 숫자가 아닌 문자 포함 | 재입력 |
| 자릿수가 다름 | 재입력 |
| 중복 숫자 포함 (`1123`) | 재입력 |
| 앞뒤 공백 | `trim()` 후 정상 처리 |
