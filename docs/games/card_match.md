# 🃏 카드 뒤집기 (CardMatch)

> 뒤집힌 카드를 2장씩 열어 같은 그림의 쌍을 모두 찾는 기억력 게임

| 항목 | 내용 |
| --- | --- |
| 클래스 | `CardMatch extends MiniGame` |
| 파일 | `src/games/CardMatch.java` |
| 담당 | 심소민 |
| 두뇌 영역 | 기억력 |
| 구현 난도 | 중 (화면 지우기, Hard 섞기) |

---

## 1. 규칙

1. 카드가 모두 뒷면(`■`)으로 깔립니다. 카드에는 같은 그림이 2장씩 있습니다.
2. 플레이어가 카드 번호 2개를 고르면 두 장이 앞면으로 열립니다.
   - **같은 그림**: 그대로 열린 채 남습니다.
   - **다른 그림**: 1.5초 보여준 뒤 화면을 지우고 다시 뒷면으로 돌립니다.
3. 2장을 한 번 여는 것이 **시도 1회**입니다. 제한 횟수 안에 모든 쌍을 찾으면 성공입니다.

## 2. 화면 예시

```
=== 카드 뒤집기 (Normal) ===  남은 시도 17/20 · 찾은 쌍 3/8

  [ 1] ■   [ 2] B   [ 3] ■   [ 4] ■
  [ 5] ■   [ 6] ■   [ 7] B   [ 8] ■
  [ 9] D   [10] ■   [11] ■   [12] D
  [13] ■   [14] F   [15] F   [16] ■

첫 번째 카드: 3
두 번째 카드: 10
  → [ 3] A   [10] G   틀렸습니다! (1.5초 후 사라집니다)
```

**카드 그림은 알파벳 `A`~`H`를 권장합니다.** `★ ♥ ♣` 같은 기호는 Windows 콘솔 글꼴에 따라 두 칸을 차지하거나 `?`로 깨져서 줄 정렬이 무너집니다. Day 1에 셋의 컴퓨터에서 기호가 잘 나오면 그때 바꿔도 됩니다.

## 3. 난이도별 설정

| 난이도 | 판 크기 | 쌍 개수 | 시도 제한 | 특수 규칙 | 시간 보너스 기준(제안) |
| --- | --- | --- | --- | --- | --- |
| Easy | 4×2 | 4쌍 | 12회 | 없음 | 90초 |
| Normal | 4×4 | 8쌍 | 20회 | 없음 | 180초 |
| Hard | 4×4 | 8쌍 | 20회 | **3회 연속 실패 시 남은 카드 위치 섞임** | 180초 |

**시도 횟수 근거**: 기억이 완벽하면 N쌍은 대략 N ~ 1.6N회 안에 끝납니다(처음 여는 카드는 운). 그래서 Easy 4쌍에 12회(3배), Normal 8쌍에 20회(2.5배)를 주면, 기억을 활용하면 성공하고 무작위로 찍으면 실패하는 선이 됩니다.

## 4. Hard: 섞기 규칙

- 연속 실패 횟수를 셉니다. 쌍을 찾으면 0으로 초기화합니다.
- 3회 연속 실패하면 **아직 못 찾은 카드끼리만** 위치를 섞습니다. 이미 찾은 쌍은 그대로 둡니다.
- 섞을 때 `⚠ 카드가 섞였습니다!`를 표시하고 연속 실패 횟수를 0으로 초기화합니다.

**왜 규칙 변화인가**: Normal에서는 "본 것을 기억"하면 되지만, Hard에서는 "실패를 쌓지 않도록 확실한 것부터 연다"는 전략 판단이 필요해집니다. 판 크기는 Normal과 같고 규칙만 다릅니다.

**남은 카드만 섞는 방법 (힌트)**: 못 찾은 카드의 **위치 목록**과 **그림 목록**을 따로 뽑고, 그림 목록만 섞은 다음 같은 위치에 다시 넣습니다.

```java
        // TODO
    }

    // 필요한 보조 메서드는 private으로 직접 설계해 보세요.
    // 예: 판 출력, 카드 2장 입력받기, 남은 카드 섞기

```

### 구현 순서

1. 난이도별 판 크기, 시도 제한, 섞기 여부를 조회합니다.
2. 카드 만들기: 그림을 2장씩 리스트에 넣고 섞습니다.
3. 찾은 카드를 기억할 자료구조와 연속 실패 횟수를 준비합니다.
4. 시도 횟수만큼 반복합니다.
   1. 화면을 지우고 판을 출력합니다. 찾은 카드는 앞면, 나머지는 `■`.
   2. 카드 번호 2개를 입력받습니다(6절 검증).
   3. 같은 그림이면 찾은 카드에 추가합니다. 전부 찾았으면 성공 반환.
   4. 다른 그림이면 두 장을 보여주고 1.5초 기다린 뒤 화면을 지웁니다. Hard면 연속 실패 처리.
5. 시도를 다 쓰면 실패 반환.

### 쓸 만한 Java API

| 하고 싶은 것 | API |
| --- | --- |
| 리스트 섞기 | `Collections.shuffle(list)` |
| 찾은 카드 번호 저장 | `Set<Integer>` (`HashSet`) → `contains()`로 빠르게 확인 |
| 1.5초 대기 | `ConsoleUtil.sleep(1500)` |
| 화면 지우기 | `ConsoleUtil.clearScreen()` |
| 정렬된 출력 | `String.format("[%2d] %s", i, card)` → 번호를 2칸으로 맞춤 |

### 화면 지우기 (`ConsoleUtil`에 공통 메서드로)

- 화면을 지우지 않으면 위로 스크롤해서 답을 볼 수 있어 게임이 성립하지 않습니다.
- ANSI 코드 `"\033[H\033[2J"`를 출력하면 터미널 화면이 지워집니다.
- **IntelliJ Run 콘솔은 이 코드를 무시합니다.** 그래서 빈 줄 50개를 출력해 화면 밖으로 밀어내는 방법을 함께 씁니다.
- `Thread.sleep()`은 `InterruptedException` 처리를 강제합니다. 게임마다 try-catch를 쓰지 않도록 `ConsoleUtil.sleep()` 안에서 한 번만 처리합니다.

## 6. 입력 검증 (시도 차감 없음)

| 입력 | 처리 |
| --- | --- |
| 숫자가 아님 / 범위 밖 번호 | 재입력 |
| 이미 찾은 카드 번호 | 재입력 ("이미 찾은 카드입니다") |
| 두 번째에 첫 번째와 같은 번호 | 재입력 |
